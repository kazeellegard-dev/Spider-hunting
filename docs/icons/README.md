アプリアイコンを決めるまでに作った案を、すべて残しています。今後のアップデート（季節のアイコン、イベント、ストアの画像など）で使うときの参考にしてください。

## 採用したアイコン

**R1「基本形」**（第5弾）。2026年10月に決定しました。

- Q1 のオレンジ背景
- Q2 の巣：アイコンのふちまで張り、結び目をつける
- Q5 の朝つゆ
- クモは、第1弾 K1「まんまるクモ」のまま

| ファイル | 中身 |
|---|---|
| `final/icon.svg` | もとの絵（SVG、100×100の座標で描画） |
| `final/icon-1024.png` | App Store 用 1024×1024（透明なし） |
